# Hercules Community Culture & Values

## Our Culture

Hercules isn't just a technical project—it's a community united by a shared belief: **AI should be intelligent, autonomous, and genuinely useful without sacrificing user freedom.**

We are:
- **Builders** who create, experiment, and push boundaries
- **Learners** who stay curious and improve constantly
- **Collaborators** who believe in the power of community
- **Rebels** who question defaults and build alternatives
- **Humans First** who remember why we build

## Community Principles

### 1. **Open & Transparent**
- Code is public and auditable
- Development happens in the open (GitHub discussions, issues)
- Roadmap is public and community-influenced
- No hidden features or secret development

### 2. **User Autonomy**
- Users own their data and conversations
- Can export everything anytime
- Can host their own instance
- Can fork and modify the codebase
- No lock-in or forced upgrades

### 3. **Quality Over Speed**
- Comprehensive testing before release
- Production-grade error handling built in
- Security audits and penetration testing
- Documentation is as important as code
- Performance matters

### 4. **Inclusive & Diverse**
- Welcome all skill levels (beginners to experts)
- Multiple ways to contribute (code, docs, design, feedback)
- Respect for different perspectives and approaches
- Support for multiple languages and platforms
- Active moderation against harassment

### 5. **Research-Driven**
- Informed by latest AI/ML research
- Publish findings and learnings
- Partner with academic institutions
- Contribute to open science
- Experiment with new ideas

## How to Contribute

### 🐛 Report Issues
Found a bug or have a suggestion?
1. Check [existing issues](https://github.com/mintoriakamoto/Hercules/issues)
2. [Create a new issue](https://github.com/mintoriakamoto/Hercules/issues/new) with:
   - Clear description of problem/request
   - Steps to reproduce (if bug)
   - Expected vs actual behavior
   - Environment details (OS, Python version, etc.)

### 💻 Contribute Code
Help us build better:
1. Fork the [repository](https://github.com/mintoriakamoto/Hercules)
2. Create a feature branch: `git checkout -b feature/amazing-thing`
3. Make your changes with tests
4. Submit a pull request with clear description
5. Code review and merge!

**Guidelines:**
- Follow [CONTRIBUTING.md](CONTRIBUTING.md)
- Write tests for new features
- Update documentation
- Keep commits atomic and descriptive
- One feature per PR

### 📚 Improve Documentation
Documentation is crucial:
- Suggest improvements to [website/docs/](website/docs/)
- Add examples and tutorials
- Translate to other languages
- Create video guides
- Write blog posts about Hercules

### 🎨 Design & UX
Help make Hercules beautiful:
- Suggest UI/UX improvements
- Create mockups or prototypes
- Design new features
- Review for accessibility (WCAG compliance)
- Contribute to [BRANDING.md](BRANDING.md) system

### 🧪 Test & QA
Help ensure quality:
- Test new releases before GA
- Report edge cases and bugs
- Test on different platforms
- Stress test performance
- Security testing and audits

### 🗣️ Community Support
Help fellow users:
- Answer questions on [GitHub Discussions](https://github.com/mintoriakamoto/Hercules/discussions)
- Write tutorials and how-tos
- Help translate documentation
- Build and share skills/plugins
- Mentor new contributors

### 🎤 Share Your Story
Tell us how you use Hercules:
- Write case studies
- Share use cases on discussions
- Present at community meetings
- Contribute to documentation examples
- Help with marketing and awareness

## Contribution Recognition

### Levels
- **Contributor** - 1-2 merged PRs, we'll add you to README
- **Member** - 5+ meaningful contributions, invite to GitHub organization
- **Core Team** - Regular contributions, maintain key areas, attend planning meetings
- **Ambassador** - Represent Hercules in community, events, speaking

### Recognition Programs
- **Hall of Fame** - Top contributors featured on website
- **Skill Award** - Best community-created skill each quarter
- **Documentation Star** - Best doc/guide contributions
- **Community Hero** - Most helpful community support
- **Innovation Prize** - Most creative/novel feature

## Code of Conduct

### We Are Committed To:
- Creating a safe, inclusive environment
- Treating all community members with respect
- Listening to and learning from feedback
- Swift action on harassment or inappropriate behavior
- Transparent moderation and conflict resolution

### Expected Behavior:
- Be respectful and professional
- Accept constructive criticism gracefully
- Focus on ideas, not personal attacks
- Acknowledge and learn from mistakes
- Help others and support the community

### Unacceptable Behavior:
- Harassment, discrimination, or hate speech
- Personal attacks or insults
- Spam or intentional disruption
- Sexual harassment or inappropriate content
- Threats or intimidation

**Enforcement:** [Full Code of Conduct](CODE_OF_CONDUCT.md)
